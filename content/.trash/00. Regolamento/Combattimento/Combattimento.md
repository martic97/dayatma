Il combattimento in Pathfinder si svolge in **round**. Ogni personaggio agisce durante il proprio turno seguendo l'ordine stabilito dall'**iniziativa**.
Durante il proprio turno un personaggio può compiere diverse azioni, attaccare, lanciare incantesimi o utilizzare capacità speciali.

---

# Formule principali

| Meccanica | Formula |
|---|---|
| **Tiro per Colpire in mischia** | BAB + Mod. [[Forza]] + Mod. Taglia + Modificatori |
| **Tiro per Colpire a distanza** | BAB + Mod. [[Destrezza]] + Mod. Taglia + Modificatori |
| **Classe Armatura (CA)** | 10 + Armatura + Scudo + Mod. [[Destrezza]] + Mod. Taglia + Modificatori |
| **Iniziativa** | 1d20 + Mod. [[Destrezza]] + Modificatori |
| **Bonus Manovra in Combattimento (BMC)** | BAB + Mod. [[Forza]] + Mod. Taglia |
| **Difesa Manovra in Combattimento (DMC)** | 10 + BAB + Mod. [[Forza]] + Mod. [[Destrezza]] + Mod. Taglia |
